# v2.4.0 解題與管理流程升級

- 正確率將所有待核對答案排除，另列參考答案吻合率與教師覆核正確率；題目有誤與無參考答案不計入。
- 學生紀錄先套用伺服器搜尋，再以每頁 20 筆載入；日期、科目、收藏與關鍵字可一起使用。
- GPT-6 Luna、Sol、Astra 可選；現行模型設定不會自動變更。快速／均衡／精準先套用草稿，測試、儲存及上一版還原分開操作。測試使用 API 額度。
- `/api/solve` 建立唯一任務，Vercel Workflow 在伺服器執行圖片檢查、額度保留、模型解題及結果儲存。學生送出完成後可離開；`/api/solve-jobs` 恢復進度及结果。
- 重複送出使用同一任務，跨分頁最多一個進行中任務。資料庫原子保留／退還額度；付費步驟不自動重試，避免不確定的重複模型費用。儲存結果可重試，歷史紀錄以任務 ID 去重。API 供應商故障仍可能使任務失敗，學生可明確重試原題；失敗原題可在 7 天內重試。
- 分頁、總覽期間、全站題目篩選與題目详情使用網址參數；總覽新增待處理工作。
- 圖庫支援每批 10 張上傳、每批 50 張啟用／停用／移除。AI 提供標籤與說明草稿，須人工確認；引用紀錄含解題與追問，教師僅查看授權學生。
- LINE 真人教師 API 串接依需求延後，既有連結維持。

## 部署

先套用 `20260924092838_durable_solve_and_model_configuration.sql`，再部署程式。保留 Supabase、Session、OpenAI 與 Gemini 現有環境變數。Vercel 上 Workflow 自動使用 Vercel World；不可將 `WORKFLOW_TARGET_WORLD=local` 設定到正式環境。正式環境的 Workflow 路由由 SDK 管理驗證。保留舊模型作為回復選項。

## 驗證

`node tests/upgrade-v240.cjs` 加上既有答案、學生批次與圖庫測試。資料庫交易測試驗證額度去重、退額度去重、設定快照及 RLS，測試交易已回滾。瀏覽器驗證手機配置還原、篩選與重新整理、任務恢復及結果顯示。Workflow 整合測試使用本機模擬資料庫／模型，實際執行 Workflow 引擎，驗證回應返回後繼續執行、結果入庫及去重；不產生正式模型費用。
